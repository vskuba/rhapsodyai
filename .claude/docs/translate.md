# Translate — перевод текста кнопкой формы

> `POST /translate` — одноразовый вызов служебного workflow `translator`:
> текст + пара языков → переведённый текст. Используется кнопкой в
> переключателе языков форм. Код: `src/uvicorn/routers/translate/translate.py`.

## 1. Контракт

* Запрос: `{text, language_from='ru', language_to='en'}`.
* Ответ: `{result}` — переведённый текст.
* Авторизация: `AuthChecker([])` — любой залогиненный («вне ноды» — агент
  `translator` привязан к служебной ноде, доступ не ограничен нодами ролей).
* Пустой текст (после `strip`) → 400. Таймаут 60 с → **504**.
* Зарегистрирован с `include_in_schema=False` — в OpenAPI не виден.

## 2. Как запускается

Агент ищется **по имени** `translator` (не по id — id не стабилен между
инсталляциями). Дальше стандартная цепочка `framework_model_create` +
`framework_workflow_run` + `asyncio.wait_for` (см. `chat.md`, `ai_framework.md`):

* отдельный `session_uuid` на каждый запрос — переводы не смешиваются с
  историей чатов;
* `companion_id=None`, а не `0`: у `agent_session.companion_id` FK на
  `companion`, `0` нарушает внешний ключ, `NULL` допустим;
* переменные: базовые + `language_from` / `language_to`, затем
  `ai_workflow_variables_defaults_apply`.

## 3. ⚠ Агент ищется по имени

`AgentRepository.find_one_by({'name': 'translator'})` — если в инсталляции
переименовать агента или удалить его, роут вернёт 404 «Агент 'translator' с
workflow не найден», а не упадёт на null. Имя — договорённость между кодом и
сидом, она не проверяется при старте.

❌ Переименовать агента `translator` в админке «для порядка» — кнопка перевода
молча сломается до первого клика.

## Грабли

1. **Считать, что перевод идёт по ноде пользователя** — §1, «вне ноды»: модель
   берётся от ноды агента `translator`, не от ноды залогиненного.
2. **Ставить `companion_id=0`** — §2, FK падает; только `None`.
3. **Ждать историю перевода** — §2, сессия одноразовая; `/chat/messages` для
   этих uuid ничего не найдёт осмысленного.
4. **Переименовать агента `translator`** — §3, роут найдёт его только по имени.
