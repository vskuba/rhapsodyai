* Эндпоинтов — ноль, `include_in_schema=False` делает это ещё и невидимым
  в OpenAPI.
* Логики — нет; файл не импортирует ничего, кроме FastAPI.
* Контента на странице — пустая `.playwright-container`.

❌ Искать «API Playwright» в `/api/playwright/*` и ждать ответа — 404.

❌ Путать с `browser.md`: там реальный сервис с Chromium и API :8014, здесь —
место для будущего прокси.
