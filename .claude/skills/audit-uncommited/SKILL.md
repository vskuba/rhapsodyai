name: audit-uncommited
description: Автоматический анализ всех незакоммиченных файлов
---

Пожалуйста, выполни этот воркфлоу строго по шагам, используя доступные инструменты:

1. Выполни команду `git status --porcelain`, чтобы найти все измененные, созданные и неотслеживаемые файлы.
2. Отфильтруй и выдели из этого списка файлы кода (например, `.py`). Если незакоммиченных файлов нет, сразу скажи мне об этом и заверши работу.
3. Полностью прочитай файл `claude.md` в корне проекта, чтобы взять актуальные правила, архитектуру и соглашения.
4. Для каждого найденного незакоммиченного файла сделай следующее:
   - Проверь синтаксис (особенно корректность импортов, работу с типами, правильное использование асинхронности и `await`).
   - Проверь бизнес-логику кода на корректность, безопасность и наличие явных или скрытых багов.
   - Сверь реализацию в файле с требованиями из `claude.md`. Убедись, что код не нарушает зафиксированные там архитектурные договоренности.
   - Если появились новые важные изменения, которые должны быть зафиксированы в `claude.md`, то добавь их туда.
5. Выведи для меня краткий и структурированный отчет по каждому проверенному файлу с конкретными замечаниями или вердиктом "Всё отлично". Если найдены ошибки, предложи готовые варианты исправлений.
