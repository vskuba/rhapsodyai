# Инструкция для Claude Code для команды /sync

Когда пользователь вызывает команду `/audit-sync`, ты обязан выполнить следующие шаги:

1. **Контекст**: Изучи результаты предыдущего аудита файлов (если они есть в истории чата) или быстро перепроверь, какие пункты `CLAUDE.md` сейчас не соответствуют реальному коду проекта.
2. **Развертывание**: Запусти мультиагентный режим (вызови инструмент `Agent` / fan out subagents) для параллельной работы.
3. **Актуализация**: Измени и перепиши текст в файле `CLAUDE.md` так, чтобы все устаревшие пункты стали на 100% актуальными и отражали текущее состояние кодовой базы (пути к файлам, настройки Docker, команды запуска тестов и т.д.).
4. **Валидация**: После внесения изменений убедись, что структура файла `CLAUDE.md` не нарушена и осталась легко читаемой.
5. **Отчет**: Выведи пользователю краткий список того, какие именно пункты были успешно обновлены.
