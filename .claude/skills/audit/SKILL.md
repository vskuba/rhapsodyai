# Инструкция для Claude Code

Когда пользователь вызывает команду `/audit`, ты обязан строго следовать этому алгоритму:
1. Запусти мультиагентный режим (вызови инструмент `Agent` для развертывания субагентов / fan out subagents).
2. Прочитай текущий файл CLAUDE.md.
3. Проведи аудит всех файлов в проекте (маршруты, тесты, конфигурации).
4. Найди, какие пункты в CLAUDE.md устарели или не соответствуют реальному коду.
5. Выведи их четким пронумерованным списком.
6. ВАЖНО: Ни в коем случае не изменяй файлы на диске. Только анализ и вывод отчета.
