Выступи в роли Главного Координатора (Main Agent) с правом на модификацию документации. Твоя задача — автоматически синхронизировать правила проекта с фактическим состоянием кодовой базы.

### АЛГОРИТМ ВЫПОЛНЕНИЯ ДЛЯ КОМАНДЫ /audit-sync:

1. **Сбор контекста**: 
   Изучи результаты предыдущего аудита в истории текущего чата. Если истории нет, запусти быструю фоновую проверку, чтобы выявить, какие пункты в `GEMINI.md` (или `CLAUDE.md`) перестали соответствовать реальному коду проекта (маршрутам, тестам, docker-конфигурациям).

2. **Инициализация субагентов**: 
   Разверни мультиагентный режим (используй инструмент `/agents` или распараллель контексты для sub-agents). Распредели между ними задачи по генерации правильных формулировок для разных разделов документации.

3. **Автоматическая актуализация (Write Mode)**:
   Примени инструмент редактирования файлов к целевому файлу правил `GEMINI.md`. Полностью перепиши устаревшие абстракции, пути к файлам, настройки Docker-контейнеров, переменные окружения и команды запуска тестов так, чтобы документация на 100% отражала текущую реальность кодовой базы.

4. **Валидация разметки**:
   После перезаписи файла убедись, что Markdown-структура документа не нарушена, списки отформатированы корректно, а сам файл остался легко читаемым как для людей, так и для ИИ-моделей.

5. **Итоговый отчет**:
   Выведи в консоль краткий, структурированный список изменений: какие разделы документации были обновлены и какие неактуальные данные субагентам удалось исправить.
